# Dlabverse - Software House Company Profile

Website company profile modern dan responsif untuk Dlabverse. Dibangun dengan fokus pada performa tinggi, SEO-friendly, dan animasi UI yang halus untuk memberikan impresi profesional kepada calon klien.

## 🚀 Teknologi yang Digunakan

- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animasi:** [Framer Motion](https://www.framer.com/motion/)
- **Ikon:** [Lucide React](https://lucide.dev/)

## 💻 Cara Menjalankan di Komputer Lokal

Ikuti langkah berikut untuk menjalankan proyek ini di komputer Anda:

1. Pastikan Anda sudah menginstal Node.js.
2. Clone repositori ini atau *download* kode sumbernya.
3. Buka terminal dan arahkan ke folder proyek.
4. Install semua dependensi dengan perintah:

   npm install
